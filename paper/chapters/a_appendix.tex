\subsection{Data Collection Notes}

All funding information was collected from Crunchbase and Tracxn databases and cross-validated across multiple sources. GitHub repository links are verified as active and pointing to the primary product codebase for each company. The GitHub URLs listed use abbreviated format (without https://) for space efficiency; the automated analysis pipeline will use full URLs for repository cloning.

Series D, E, F, and G funding rounds are documented in the complete dataset but excluded from these summary tables for space constraints. The dataset represents a comprehensive sample of venture-backed open-source software companies that raised Series A funding during or after 2009, with at least 36 months elapsed between Series A and data collection to allow for subsequent funding evaluation.
